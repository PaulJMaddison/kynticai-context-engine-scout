## Current commercial status

Scout should not be offered or described as:

- a current KynticAI product;
- a supported paid-pilot platform;
- an open-source first tier leading into Fortress or Elite;
- a production migration route into the current KynticAI platform;
- a complete description of current KynticAI capabilities or architecture.

The public repository remains available as a historical/open-source proof of concept demonstrating earlier work around authorised data ingestion, customer-controlled context construction, relationship linking, provenance and API delivery.

Current KynticAI products, deployments and commercial engagements are separate from Scout.

For current information, see https://kynticai.com.
