# KynticAI Scout v2.9.0

KynticAI Scout v2.9.0 is the first clean, fully audited public release of the
open-source data-plane foundation. It completes the 11-package work backlog
that followed the v2.8.0 public launch, closing the product-hardening,
delivery-engineering, and documentation gaps found in the 2026-08-04 audit.

## Highlights

- Hardened cross-tenant authorisation on the admin REST endpoints and guarded
  audit CSV exports against formula injection (Security).
- Hardened the API surface: operation IDs on legacy endpoints and a
  configuration-derived SaaS architecture overview.
- Fixed the one known SDK/API contract mismatch: `FactValueType` is now typed
  in the .NET and TypeScript SDKs with a tolerant JSON converter, and the .NET
  package stays self-contained.
- Re-enabled and hardened CI/CD (OSS-013): independent backend, frontend, and
  public-safety jobs; the pilot-readiness gate now requires safe active
  workflows; integration tests are trait-tagged.
- Documented and verified the browser proof (6/6 Playwright specs, opt-in).
- First tagged release for the Score API, the Discovery Agent MCP server, the
  n8n integration nodes, the public docs site, and the Scout pilot setup
  wizard.
- Completed the connector authoring and marketplace documentation (OSS-019),
  including a new end-to-end authoring tutorial.
- Added the migration tool and pilot lead-capture user docs, plus a committed
  fresh OpenAPI export.
- Refreshed the roadmap to list shipped work and reconciled the two
  changelogs into a single canonical source.

## Verification

- .NET restore, Release build (warnings as errors), and all four test projects
  (unit, SDK, integration, end-to-end) pass.
- Web app install, lint, unit test, and build pass; TypeScript SDK build and
  test pass; docs-site build passes.
- The public-safety scan is clean and is enforced by CI and the
  pilot-readiness gate.
