# Scout retirement notice

KynticAI Scout has been retired as an active product.

This repository is retained publicly as a historical/open-source proof of concept. It records an earlier KynticAI approach to customer-controlled ingestion, context construction, relationship linking, provenance, APIs, SDKs and local deployment.

## Effective status

From September 2026:

- Scout is not part of the current KynticAI production product suite.
- Scout is not a supported sales entry point into KynticAI.
- No new Scout product features are planned.
- No new customer pilots should be based on Scout as the commercial product.
- The repository should be treated as frozen historical reference material.
- Existing technical documentation remains available to explain the code that is preserved here.

## Relationship to current KynticAI

The current KynticAI platform has evolved substantially beyond Scout.

This repository does not describe or contain the finished production architecture and must not be used to infer the boundaries, internal mechanics or implementation of current private KynticAI products.

Current private capabilities — including the production reasoning, governed evidence construction, attention, outcome modelling, governed intervention/execution, outcome memory, compounding intelligence, Fortress internals and Elite integration — remain outside this public repository.

Older repository documentation may describe Scout as the first step in a `Scout -> Fortress -> Elite` product progression, a supported paid-pilot route, or a production migration path. Those statements are historical and are superseded by this notice.

## Why the repository remains public

Scout contains useful engineering work and demonstrates several ideas that remain valuable as public reference material:

- customer-controlled data access;
- source provenance and evidence retention;
- semantic/context construction;
- relationship linking;
- API and SDK exposure;
- connector patterns;
- self-hosted/local deployment approaches.

Keeping the repository available preserves that work without presenting it as the current KynticAI product architecture.

## Maintenance and support

The project is retired. Users should not assume:

- feature development;
- production support;
- security patches;
- compatibility guarantees;
- operational SLAs;
- a supported migration path into current KynticAI products.

The code remains available under its existing MIT licence.

For current KynticAI information, see https://kynticai.com.
